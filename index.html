🏠 EVA — what it is

← Table of contents

Highlights

🔑 Full login automationSeparate Steam per account, Purple via NC or Google, terms and cloud prompts handled, hidden game windows.
🧭 Run order with character loopAutoquest → Expedition → Sealed Dungeons → Auto mining → AFK Farm → Abyss, then the next character slot — once per character per game day (04:00).
🛡 Exclusive proxy per accountSOCKS5 with HTTPS/latency testing, fixed-IP reservations, IPv6 blocking, TUN mode or the experimental built-in IPv4 backend.
◎ AI captchaBuilt-in solver, no key needed (YesCaptcha optional), up to 3 attempts, penalty-aware: activities wait out the restriction and resume on their own.
💰 1,000,000 Kinah/dayAFK Farm under a daily Kinah cap (1,000,000) that renews at 04:00.
🧰 Housekeeping routinesMonolith feathers, Market relisting, warehouse, resurrection, supplies, equipment enhancement — on random intervals.

Quick start

  1. Unpack the folder and run SysOpsHelper.exe — no installer, the .NET runtime ships inside (details).
  2. Enter your card key from the store; the app validates it online (app updates use a signed channel).
  3. Add your game accounts and link a proxy to each one — Steam and Purple alike.
  4. Open Configure for a profile, tick the activities in the Run order and press Start.

Requirements at a glance

  • Windows 10 or 11, 64-bit.
  • The proxy engine additionally needs .NET Framework 4.7.2+ and the Windows Packet Filter driver.
  • The multi-account version requires the VK Multi-Account tool; the single version does not support VK.

🚀 Install & updates

← Table of contents

First run

  1. Download the distribution (gofile.io/d/DtUcYKaT) and unpack it as a whole — the app verifies its own components (proxy-engine completeness, native helpers) at startup.
  2. Run SysOpsHelper.exe. No installer, no services; everything stays inside the folder.
  3. Enter the card key you received after purchase. The license is checked against the store’s online endpoint (app updates additionally use a signed manifest).
  4. Allow the proxy-engine host process in Windows Firewall (private and public networks) when Windows asks — the firewall prompt shows its name.
  5. Set the game window size in the app’s settings before installing accounts — windowed and fullscreen both work.

How updates work

  • Updates arrive through a signed online channel: “Each file is checked against the signed manifest” — invalid hash or signature aborts the update.
  • A new version is announced even while accounts are running, with a “Stop accounts and update” option — running sessions are never killed mid-activity by default.
  • The app closes, updates and reopens by itself; the game stays open. A separate AION2 Update.exe handles the game-side files.
  • When the bot is stopped it checks for updates every six hours; you can also press Check for updates at any time.

Security-mode & antivirus

Antivirus products sometimes flag the proxy-engine host process. The app offers a Safe mode in that case: the proxy engine stays off and accounts open directly, without proxies. If you want proxies, whitelist the executable and the folder.

Local data security

  • The accounts file is fully encrypted for the current Windows user and the data folder uses restricted permissions.
  • Internal session identifiers are derived per machine, and the updater no longer uses encoded in-memory commands — fewer false antivirus alerts during updates.

Good to know

  • The window name shown in titles, tray and texts is rebrandable by editing projeto.json → nome_mostrado (that’s why some copies are called “UNICOM”).
  • Deleting or editing files inside proxy-engine\ breaks the proxy features — reinstall instead of patching by hand.
  • If authorization is rejected after an update, update the app first: “Invalid license response. Update the app and the plugin.”

👤 Accounts & login

← Table of contents

Where to find it

  1. Main window → Accounts
  2. “+ Add Steam account” / “Add account for automatic login”
  3. Open an account’s individual settings

What it does

  • Registers, edits and deletes Steam and Purple accounts; race, server and character slot are configured per account (the slot field was called “Character” before 5.5.0).
  • Logs in automatically: fills the Steam login (accepting the Steam agreement, confirming “Play anyway” on an outdated cloud) and drives Purple, including NC or Google login.
  • Opens a separate Steam instance per account so many accounts can log in on one PC.
  • Recognizes games that are already open; starts and stops each account; cancels a stuck login.
  • Shows class, level, status and per-account logs, respecting the single/multi license.
  • Arranges game windows in grids from 1 × 1 up to 6 × 6; the game opens at 1280 × 720 by default.

How to use it

  1. Click “+ Add Steam account” (or add a Purple account) and enter the credentials.
  2. Pick race, server and slot. The server list is grouped by region (North America East/West, Europe, South America, …).
  3. Set the game window mode and size in the account’s settings, then click Start.
  4. If a login stalls more than 10 minutes it is stopped — resolve it in the game window and press Start again.

Settings explained

SettingWhat it does

Good to know

  • Purple asks to accept the AION 2 terms once per account — the bot continues on its own after that.
  • “Another account is entering the game. Wait for it to finish or cancel that login and click Start again.”
  • If Purple’s Start Game stays disabled for a long time, the game is probably already open or an update/verification is in progress — check Purple and start again.
  • Purple accounts run through the proxy too — since 5.8.0 Purple connects only after binding to the account’s proxy, never through your real IP.
  • A new account starts with recommended settings: Autoquest (main and side quests), Expedition, Auto mining, AFK Farm up to the Kinah limit and the Abyss on both floors.

🛡 Proxy (SOCKS5)

← Table of contents

Where to find it

  1. Main window → Proxy tab
  2. Account settings → proxy assignment

What it does

  • Imports SOCKS5 proxies one by one or in bulk and links each account to its own exclusive proxy.
  • Tests each proxy: “Active means a tested HTTPS connection”, with latency shown and per-step diagnostics (a step over 8 seconds is reported).
  • Keeps fixed-IP reservations per account; after rotating IPs at the provider, release the old reservation from the proxy’s menu so the account can be re-bound.
  • Blocks the game’s IPv6 in Windows so no traffic can leak outside the proxy; if blocking fails, the launch is cancelled.
  • Offers two engines: exclusive TUN mode or the experimental built-in IPv4 backend (“Windows DNS, no IPv6 isolation. Its own games end with the session”).
  • Supports automatic distribution: each account receives a dedicated proxy profile before start.
  • On the first account with a proxy the bot sets up the network driver and the engine by itself — nothing to download (since 5.8.0).

How to use it

  1. Add proxies (own list or via the built-in “Buy proxy on Webshare” link) and let the test confirm HTTPS + latency.
  2. Assign one exclusive proxy per account — sharing a profile between reservations is refused until fixed.
  3. Enable the proxy mode you want (TUN exclusive or proxy-engine experimental IPv4) and close running game sessions before switching it.
  4. Start the account; the bot opens the game inside the proxy session (“Connecting this account’s game to the proxy…”).

Settings explained

SettingWhat it does
Add SOCKS5 proxySingle or bulk import; double-click edits an entry.
TestHTTPS connectivity + latency; a test step exceeding 8 s is flagged in the per-step diagnostics.
Fixed IP reservation“Choose a free proxy to fix an old binding. Fixed IP reservations are preserved.”
TUN exclusiveFull tunneling for the account’s game.
built-in IPv4 (experimental)DNS via Windows, no per-account IPv6 isolation; games opened by the bot are closed when the session ends.

⚠️ Purple accounts run through the proxy too. Since 5.8.0 the game Purple connects only after it is bound to the account’s proxy — never through your real IP. The engine also requires .NET Framework 4.7.2+ and may need a reboot after the Windows Packet Filter driver installs.

◎ Captcha · AI

← Table of contents

Where to find it

  1. Main window → Captcha tab
  2. Works automatically during any activity

What it does

  • When the game shows a verification, the bot stops the current activity, reads the image straight from the game and solves it automatically with the built-in EVA captcha service — no key or balance needed.
  • An optional YesCaptcha key can be configured on this computer (the field can be shown or hidden).
  • Tries up to three times; the activity only resumes after the previous character is confirmed and the verification is gone.
  • Without a confirmed solution the bot closes only that account’s game and reopens it right away through the normal login; a game opened outside the bot is only closed.
  • Knows about the game’s restrictive penalty: “Every activity of this account stays stopped and resumes by itself when it ends” (with the minutes left shown).

How to use it

  1. Nothing to configure: the built-in EVA service solves captchas for every customer — no key or balance needed. Optionally, a YesCaptcha key can be added in the Captcha tab.
  2. Leave everything else to the bot: detection → solve → confirm → resume. The activity log records every step.

Good to know

  • If the image can’t be found in the game’s memory, the game has likely been updated — an app update follows on the signed channel.
  • “Captcha: no solution within the time limit; closing and reopening this account’s game.”
  • Penalty files (captcha-penalty.json, captcha-records.json) persist what happened so restarts don’t lose state.

🧭 Run order

← Table of contents

Where to find it

  1. Configure window (per profile) → Run order tab
  2. “Copy to accounts” pushes the copied options to the checked accounts

What it does

The Run order is the character’s daily plan — “The order in which Start does the objectives, after the routines, from top to bottom.” Each activity can be toggled, reordered (↑/↓) and configured (⚙):

  1. Autoquest — “Green quests first, then the main ones, up to the level in the Autoquest tab or until there are no quests.”
  2. Expedition — “Expeditions up to the amount beside it (the same as in the Expedition tab). The count resets on its own at 04:00.”
  3. Sealed Dungeons — “The sealed dungeons switched on in the Sealed Dungeons tab, one at a time, until none is left (once per character, from the chosen level).”
  4. Auto mining — “Routes in the Auto mining tab up to the server’s daily gathering limit.”
  5. AFK Farm — “Spot from the AFK Farm tab up to the daily Kinah limit (the spots’ minutes do not apply).”
  6. Abyss — “Floors ticked on the Abyss tab, one after the other, until each one’s time runs out (level 45 and 1000 power points).”

Rules below the list

RuleWhat it does
Die X times on the same quest: move on to the nextAfter X deaths (default 10) on the same quest, it is set aside for 30 minutes and the next one starts. The green ones still come first.
When everything is done, switch characterThe character returns to the selection screen of the same game and the next slot runs the same order, in a loop. It can also create new characters up to a chosen total (free slots only — locked slots are never touched). Each character does the order once per game day (04:00). The gear opens its settings.

Good to know

  • Activities hand over to each other automatically: “Abyss: can enter now; AFK Farm hands over to the Abyss”, “Auto mining can come back now: Farm AFK hands over to gathering”.
  • Steps that become unavailable are postponed and resumed when they are available again; the whole order restarts at 04:00.
  • Everything configured here is per profile — Copy to accounts copies the checked options (Autoquest, AFK Farm, mining, Dungeons, Routines, Humanization and Speed/FOV) to the checked accounts; each keeps its own class and the expeditions already done.

📋 Autoquest

← Table of contents

Where to find it

  1. Configure window (per profile) → Autoquest tab
  2. Run order → item 1

What it does

  • Completes missions automatically, preferring green side quests first, then the configurable main quests; stops at the chosen level (0 = no limit).
  • Accepts side quests required by a main quest’s step and follows quest destinations.
  • Auto-retaliates against aggressors and resumes the mission; ranged classes keep their distance — “attacks and backs away from the approaching monster, keeping the range”.
  • Since 5.14 the combat distance respects the real range of your skills, so ranged classes no longer stand too far from a boss without hitting.
  • Can use its own movement speed during Autoquest (disabled when the bot stops).
  • Stuck handling: timeout without progress, new attempt for a postponed mission, option to ignore stuck missions, unstuck via return scroll.

  • Progress and problems are logged per account, so a support request can be answered from the logs alone.

⚔ AFK Farm

← Table of contents

Where to find it

  1. Configure window (per profile) → AFK Farm tab
  2. Run order → item 5

What it does

  • Hunts with your class’s skills at a chosen spot: walks the area, selects targets, attacks, loots.
  • Spots: add/remove/activate locations with a radius, a time limit in minutes (0 = no limit) and monster IDs; an empty ID list accepts all eligible targets in the area.
  • Points: reads the selected target type, captures your current position as a point, or accepts manual coordinates — several points per spot are allowed; without coordinates the character’s position is used.
  • Combat: attack distance and search radius; auto-retaliate prioritizes aggressors; against approaching monsters it “attacks and backs away… keeping the range”.
  • Spiritmaster: chooses the permanent spirit — Water, Fire, Wind or Earth.
  • Under the Run order it farms “up to the daily Kinah limit (the spots’ minutes do not apply)”. The limit is 1,000,000 Kinah per day and renews at 04:00.

Resilience (built in)

  • A spot that repeatedly kills the character, can’t be reached, or shows no attack for a while is paused and the next enabled spot takes over.
  • After many deaths in a row the farm continues in cautious mode — a smaller radius — before pausing.
  • “Daily Kinah limit reached; the Farm returns when the limit renews (04:00).”

Good to know

  • “AFK Farm on Start” runs the farm immediately after login, before the Run order.
  • There is also a pure AFK mode (“start only AFK Farm”) that skips quests entirely.
  • Spots are per profile — copy them to other accounts from the Configure window.

⛏ Auto mining

← Table of contents

Where to find it

  1. Configure window (per profile) → Auto mining tab
  2. Run order → item 4

What it does

  • Gathers natural resources from level 45, respecting the server’s daily gathering quota — “Limite de coleta do servidor atingido; coleta adiada até…” (the server limit was reached; gathering postponed until reset).
  • Routes: add/remove, name, activate, reorder; each route has a radius and resource IDs — an empty list gathers every eligible natural resource.
  • Reads the currently selected resource and adds its ID; accepts manual coordinates, several points per route; all points of a route must be on the same map.
  • Walks the route, gathers on the way, resumes the path, and repeats the routes on the current map; a configurable wait time without resources moves it to the next point.
  • Only the area of each route point is gathered — ores on the way between points are ignored; far points are reached on foot along the way (the automatic Kibelisk teleport for points over 500 m was removed in 5.5.0).
  • Auto-retaliates against aggressors and resumes gathering; can hand over to AFK Farm when limits are hit, and vice versa.
  • A map or session change ends gathering; everything is logged per account.

🏰 Sealed Dungeons

← Table of contents

Where to find it

  1. Configure window (per profile) → Sealed Dungeons tab
  2. Run order → item 3

What it does

  • Runs the dungeons switched on in the tab one at a time, once per character, from the chosen starting level (default 45).
  • The game’s completed-quest list tells it which dungeons are left — finished ones are never tried again.
  • Travels to Kibelisk, confirms the arrival, then interacts with the entrance portal.
  • Safety rails: “Dying 10 times in the same dungeon or spending more than 40 minutes in one stops the Sealed Dungeons until the next game day (04:00).”
  • When the daily limit is reached it leaves the dungeon on its own.

How to use it

  1. Tick the dungeons available to your character and set the starting level.
  2. Leave “Sealed Dungeons” enabled in the Run order (or start it individually from the tab).
  3. Each dungeon’s status is visible in the account logs.

🗺 Expedition

← Table of contents

Where to find it

  1. Configure window (per profile) → Expedition tab
  2. Run order → item 2

What it does

  • Runs Krall, Unu or Fire Temple Exploration, or Krall Conquest, the chosen number of entries per day (0 = none) — the same amount as in the Run order.
  • Solo or team mode: a team needs three members. With the multi-account tool (VK) open, matchmaking is unavailable, so the bot creates the team directly or waits for a team you created/accepted in the game.
  • Checks Ode energy before entering — 40 for Krall/Unu, 60 for Fire Temple — can use recharge items and buys a Potion/Elixir first; with “Require potions” enabled it only enters with confirmed stock.
  • Death limit (default 5) and a 1,000,000 gold cap in Conquest protect the run; auto-retaliate and own speed are configurable, speed is restored on exit. A “Use revive stone” option (on by default) revives on the spot when the stone is in the bag.
  • In Krall Conquest the bosses are taken in order — left, right, guardian, final — and the pillar is set as a checkpoint.
  • Since 5.14: in Krall Conquest the bot opens the reward chest after the final boss before leaving.
  • Counts reset on their own at 04:00; the expedition team is left automatically before entering the Abyss.

◆ Abyss farming

← Table of contents

Where to find it

  1. Configure window (per profile) → Abyss tab
  2. Run order → item 6

What it does

  • Enters the ticked Abyss floors one after the other and farms each one until its time runs out.
  • Requirements: level 45, 1000 power points, and more than three minutes on the floor.
  • Waits for 90% flight energy, flies to the chosen spot, and recharges to 100% at the nearest landing position when energy runs low mid-run.
  • Hunts monsters, supports automatic feather collection, and requests the exit with about three minutes remaining.
  • Spots can be randomized at every entry — and varied again after deaths; floor locations and monster coordinates/levels are visible in the tab.
  • Optional entry schedule: enable it and set an hour from 0 to 23 (default 22) using the PC clock — the window runs from that hour until midnight, without forcing an exit at midnight.
  • Leaves the expedition team before entering (the game does not take team members to the Abyss).

Good to know

  • “Abyss: can enter now; AFK Farm hands over to the Abyss.” — activities hand over automatically.
  • Gathering inside the Abyss stops when the daily gathering limit is reached.
  • If flight energy doesn’t reach the threshold in time, the bot leaves the Abyss on its own.

🧰 Routines

← Table of contents

Where to find it

  1. Configure window (per profile) → Routines tab
  2. “The enabled routines run on start and repeat at random intervals.”

General

  • Monolith: auto level-up with feathers; “Amount to go to the Monolith; 0 = what is missing for the next level.”
  • Market: at the routines time it interrupts the activity, opens the Market through the menu, redeems completed sales, announces tradable items and reposts unsold ones — with equipment colors and a lower/medium price; protected items are preserved.
  • Warehouse: with a full backpack after the dismantle attempt it stores Special Transformation, Common/Rare crafting materials and Common/Rare food; the deposit can run outside the expedition.
  • Survival: potion by life percentage, resurrection stone (preparing resurrection, resuming even if the confirmation doesn’t arrive in 60 s), nearby loot pickup, stuck-character recovery, and return by scroll after local attempts fail (outside instances). Keeps a minimum flight/glide energy, dodges attacks from registered bosses (leaves the attack area by the nearest side, dash facing the exit) and collects healing orbs during Autoquest. An Aion 1 mode plus character creation at the tutorial end with configured class and prefix are here too.

Rewards

  • Receives mail attachments and available presence, achievement and pass rewards.

Character

  • Expands the backpack up to a chosen total, counting expansions already made.
  • Equips titles and wings by rarity, fills empty slots, swaps weapons/equipment for compatible improvements.
  • Enhances equipment with color limits — white, green, blue, yellow, orange (runes are never enhanced).
  • Automatic Daevanion: “learns the cheapest node in all unlocked tabs.”
  • Links Mana/Vital stones into empty slots, preserving existing stones.
  • Extracts eligible equipment of chosen colors (the “item cleanup” other tabs refer to).
  • Improves learned skills according to level and points; states are visible in the log.

Supplies

  • Leaves combat and returns to Kibelisk with the Linked Return Scroll to replenish low stock.
  • Configures minimum and final quantities of Life Potion, Life Elixir and Return Scroll — all linked.
  • Searches the Item Merchant and buys only what is missing to complete the defined stock.

Events

  • Shugo Festa — Protecting the Merchants: the hourly event, saved to the bot’s routine schedule (comes turned off — enable it in Routines).
  • Mysterious Track race: the bot runs the race, dodges orange pads, whirlwinds and gates, takes speed and life orbs and glides at the launch strip; its move-speed boost is configured on the Speed/FOV page.
  • At the end of an event the reward is collected and the account returns to what it was doing.
⚠️ A detected captcha stops the routines (“routines stay stopped”) until the verification is confirmed solved.

🫥 Humanization

← Table of contents

Where to find it

  1. Configure window (per profile) → Humanization tab

What it does

  • “Adds a random wait before clicks, dialogues, looting, inventory, rewards and login steps. It only adds time, never removes it: the bot gets a bit slower and less regular.”
  • “Adds a random margin of up to 30 s when the bot checks again whether it can continue after a wait, and up to 90 s on automatic restart.”
  • Session pauses: set an active-work time; when it ends the bot stops the routines, tries to return to town with a return scroll and rests — with a variation of ±30% on the timings, resuming according to mode and map.
  • Performs occasional small camera rotations without using the physical mouse, respecting each activity’s restrictions.
  • The AFK Farm itself can take short human-like pauses — “1 to 8 min at the spot, reacting to aggression” (AFK Farm only, while hunting).
⚠️ Humanization lowers the regularity of the bot’s actions, but it does not guarantee protection against punishment. Use it at your own risk.

⚡ Speed & FOV

← Table of contents

Where to find it

  1. Configure window (per profile) → Speed/FOV tab

What it does

  • Adjusts movement speed, animation speed, attack/combat speed, field of view and maximum camera distance separately; values are saved even when disabled.
  • Enable/disable each adjustment and request a restoration; pausing and closing also restore the original values.
  • In the expedition: turns on the page’s speed adjustment with the configured percentage and turns it off on exit (default 20).
  • Mysterious Track race: raises the move speed only during the race and restores it at the end (default 20; 0 = off). In the race it avoids the orange pads, tornadoes, little critters and the purple gate, rides over the cyan pads and picks up speed and life orbs (life orbs first when life is low).
  • The combat-speed slider requires the character to have made the combat speed attribute available.
⚠️ Speed and FOV changes are visible modifications. They are optional, off by default, and used at your own risk.

❓ FAQ

← Table of contents

Is it a macro or a hack?

It is an external automation and account-management suite: it drives the game through its own interface, with optional Speed/FOV adjustments that are clearly separated and off by default.

Can I get banned?

Any automation carries risk. The bot includes Humanization (random waits, session pauses, small camera movements), and the vendor states plainly that it does not guarantee protection against punishment.

Does it support every class?

All nine classes: Gladiator, Templar, Assassin, Ranger, Sorcerer, Spiritmaster, Cleric, Chanter and Brawler. The Spiritmaster chooses a permanent spirit (Water, Fire, Wind or Earth); ranged classes get their own dodge settings.

Can I run several game windows at once?

Yes — with the multi-account tool (VK) required by the BOT MULTI version. Each account gets its own Steam instance and a slot in the window grid (1 × 1 up to 6 × 6). The Single version does not support VK.

What happens with a full inventory?

The Routines cover it: the warehouse stores Special Transformation, crafting materials and food after the dismantle attempt, the Market frees space by posting items, and an “Also extract tradable items” option (added in 5.5.0) lets the item cleanup extract tradable equipment of the chosen colors — never upgrades, worn items or quest items.

Does it handle the in-game captcha?

Yes — automatically: the built-in EVA service solves it for every customer, no key needed (a YesCaptcha key is optional), up to three attempts; without a solution it re-enters cleanly and waits out any penalty.

Which servers are supported?

The server list is grouped by region — North America (East/West), Europe, South America and others — and is updated with the app (it ships as data, not hard-coded).

Is it paid?

The license is a card key valid for 1 month; per the store’s policy there is no refund.

How do I update?

Automatically: the app checks the signed channel every six hours while stopped, waits until accounts stop, then closes, updates and reopens itself — the game stays open.
